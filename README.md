# A Vida em Escala

Página de apresentação do livro **A Vida em Escala**, de **Vania Masami Matsuno**.

## Tecnologias

HTML, CSS e JavaScript, sem dependências externas.

## Como abrir no VS Code

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador. Opcionalmente, use a extensão Live Server.

## Arquivos

- `index.html`: estrutura e textos.
- `style.css`: visual e adaptação para celular.
- `script.js`: interação sobre as escalas da vida.
- `LEIA-ME.txt`: instruções adicionais.

## Recursos

Apresentação do livro, resumo, doze capítulos expansíveis, seção da autora e exploração interativa das escalas biológicas.

A composição gráfica do livro é ilustrativa, criada em CSS. O PDF completo não está incluído. Os textos são sínteses de apresentação baseadas na obra fornecida.
